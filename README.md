# projetkenneth — Premier script Python

Petit script en ligne de commande qui demande un nom et un âge, puis calcule l'âge de l'année suivante. C'est un projet d'apprentissage.

## Lancer le script

Il faut Python 3, sans dépendance à installer.

```bash
python main.py
```
